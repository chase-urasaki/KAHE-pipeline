Installation
=============

From Source (Development)
--------------------------

Clone the repository and install in editable mode:

.. code-block:: bash

    git clone https://github.com/chase-urasaki/KAHE-pipeline.git
    cd KAHE-pipeline
    pip install -e .

Install development dependencies:

.. code-block:: bash

    pip install -e ".[dev]"

From PyPI
---------

Once published to PyPI:

.. code-block:: bash

    pip install kahe

Requirements
------------

- Python ≥ 3.10
- numpy
- astropy
- matplotlib
- scipy
